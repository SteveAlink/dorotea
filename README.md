# Dorotea
A wonderfull theme for WonderCMS

# Installation
1. Use the tab Themes in settings  
2. Scroll all the way down  
3. Insert the following:
```text
https://raw.githubusercontent.com/SteveAlink/dorotea/main/wcms-modules.json
```
4. In the list of themes, select Dorotea to install it.

# Notes
This theme doesn't contain a favorite icon. If you have one, place it in the main directory that also contains index.php.  
Use at own risk.
